# estacao-espacial-orbit

# Missão Espacial: Protocolo de Homologação em Camadas[cite: 5]

## Sobre o Projeto
Repositório público **estacao-espacial-orbit** criado para a prática do fluxo de desenvolvimento corporativo em três etapas[cite: 5]. O projeto inclui a implementação de um módulo de monitoramento de suporte de vida (níveis de oxigênio, pressão e reciclagem de água) desenvolvido para a disciplina de Garantia da Qualidade de Software[cite: 5].

## Camadas do Ambiente
A gestão do código deste projeto é dividida nas seguintes ramificações (branches)[cite: 5]:
* **develop:** Ambiente de desenvolvimento[cite: 5].
* **stage:** Ambiente de testes e homologação[cite: 5].
* **main:** Ambiente final de produção[cite: 5].
